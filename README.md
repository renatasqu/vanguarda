# Vanguarda — Radar PMO

Protótipo estático em português com Dashboard, Projetos, Simulador e Metodologia. Todos os dados são demonstrativos. Seis projetos sintéticos, dois por setor.

## Executar

Na pasta vanguarda: `python3 -m http.server 5173 --directory dist`. Abra http://localhost:5173.

Sem dependências de execução. Fontes Google são opcionais; a interface usa fontes de sistema como alternativa. Filtros, detalhes de projetos, exportação CSV e simulação de custo e prazo funcionam no navegador. Não há persistência nem integração com sistemas reais.
